A diagnostic spine for the railway control room.

पूर्वरूप से उपशय तक — drift, cause, course, response

NIDAN turns track-circuit telemetry into a ranked, explainable hypothesis. These seven screens are the product argument: a Watch alert is not a red badge, it is a named failure mode, a physical explanation, a calibrated remaining life, and a job that fits a published block. Everything here is advisory. There is no write path to interlocking, signals, routes or track circuits.

Signal, not dashboard

One spine orders the division by consequence. Colour never carries state alone; every shape has a word and a number.

Explain before you ask

Physics, model and precedent sit in one card. The technician sees the falsifier, not just the score.

Fit the block you already have

Rolling Block windows are first-class data. The best intervention is the one that needs no special block.

One coherent dataset

Every screen uses the same asset set and timestamps: 12T, 14T, 16T in cluster c-9917, with 21T as the predicted cascade. Nothing is lorem ipsum.

Static, inspectable

No build step. Tokens in assets/tokens.css, components in assets/app.css, shared shell and tabs in assets/app.js.

Deliberate limits

Advisory only. No control affordance is drawn anywhere, not even disabled: the interface cannot suggest a command path that does not exist.
